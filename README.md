# CESIM Dashboard v6 — KAIRO

## Novedades de diseño
- Logo oficial de KAIRO integrado en la aplicación.
- Favicon con identidad KAIRO.
- Logo en la barra lateral y encabezado.
- Estética visual renovada inspirada en el concepto KAIRO:
  fondos claros, azul tecnológico, tarjetas limpias y jerarquía visual.
- Se mantienen todos los datos y análisis de la v5.
- Resultados precargados automáticamente desde `resultados/`.

## Ejecutar

```bat
cd C:\Users\Candi\Desktop\cesim-dashboard-v6
python -m streamlit run app.py --server.headless true --server.port 8503
```

Abrí:

```text
http://localhost:8503
```
